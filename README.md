# Fullstack-Learning
Фаза 1. Фундамент фронтенда: HTML, CSS, JavaScript/TypeScript (месяцы 1–3)

1.1. HTML и CSS (3–4 недели)

· Семантический HTML, формы, доступность (a11y).
· CSS: каскад, специфичность, Flexbox, Grid, адаптивность (@media, clamp), container queries.
· Проект: адаптивная страница-портфолио или лендинг (только HTML/CSS, без JS).

1.2. Основы JavaScript (4–5 недель)

· Переменные, типы, функции, массивы, объекты, циклы.
· Ключевое: методы массивов (map, filter, reduce), деструктуризация, spread/rest, замыкания, this.
· DOM: выбор элементов, события, создание/удаление узлов.
· Асинхронность: Promise, async/await, fetch.
· Проект: интерактивное To-Do или погодное приложение с запросом к открытому API.

1.3. TypeScript (2–3 недели)

· Базовые типы, интерфейсы, type, generics, union/intersection types, unknown vs any.
· Настройка tsconfig.json, работа с типами в реальном проекте.
· Задание: переписать проект с 1.2 на TypeScript.

Фаза 2. Современный фронтенд: React (месяцы 4–5)

· React основы: JSX, компоненты, props, state, события, условный рендеринг, списки и ключи.
· Хуки: useState, useEffect, useContext, useReducer, useRef, кастомные хуки.
· Стилизация: Tailwind CSS или CSS Modules.
· Состояние: Zustand (локальное) + React Query / TanStack Query (серверное состояние) — это современный стандарт, Redux для старта не нужен.
· Роутинг: React Router.
· Формы: React Hook Form + валидация (Zod).
· Проект: SPA с несколькими страницами, формами, запросами к API, состояниями загрузки и ошибок. Например, трекер задач или каталог с фильтрами.

---

Фаза 3. Бэкенд: Node.js, API, базы данных (месяцы 6–8)

3.1. Node.js и Express (3–4 недели)

· Модули, fs, path, process.env, npm-скрипты.
· HTTP, REST-принципы, статус-коды.
· Express: роутинг, middleware, обработка ошибок, валидация.
· Проект: REST API для задач (CRUD) с in-memory хранилищем или JSON-файлом.

3.2. PostgreSQL и ORM (3–4 недели)

· SQL: SELECT, INSERT, UPDATE, DELETE, JOIN, GROUP BY, индексы (базово).
· Схемы, миграции.
· Prisma (или Drizzle): модели, миграции, CRUD, связи.
· Задание: перевести API с 3.1 на PostgreSQL + Prisma.

3.3. Аутентификация и безопасность (2 недели)

· Хеширование паролей (bcrypt), JWT, refresh-токены (концептуально).
· Защита роутов, базовая валидация входных данных, CORS, переменные окружения.
· Проект: API с регистрацией/логином и защищёнными эндпоинтами.

---

Фаза 4. Соединяем всё: Fullstack-интеграция (месяцы 9–10)

· Связка React ↔ API: авторизация, обработка токенов, защищённые страницы.
· Next.js (App Router): серверные компоненты, Route Handlers, серверные экшены — современный способ делать fullstack на React.
· Деплой: фронтенд на Vercel/Netlify, бэкенд на Render/Railway, база на Supabase/Neon (бесплатные тарифы для старта).
· Главный проект портфолио: полноценное приложение с аутентификацией, базой данных, CRUD, деплоем и README. Не «Todo», а что-то с реальным сценарием (трекер привычек с аналитикой, платформа для заметок с тегами и поиском).

---

Фаза 5. Подготовка к трудоустройству (месяцы 11–12)

· Алгоритмы и структуры данных: массивы, строки, хеш-таблицы, стек/очередь, два указателя, бинарный поиск. Достаточно 2–3 задач в неделю на LeetCode (Easy/Medium).
· Git в команде: code review, конфликты, rebase (базово).
· Оформление GitHub: 2–3 сильных проекта с качественными README и демо.
· Резюме и сопроводительное письмо, подготовка к рассказам о проектах (архитектура, сложности, решения).
